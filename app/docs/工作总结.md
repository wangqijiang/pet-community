## 💡 常见问题

### Q1: 如何使用新的 Picker 组件？
```vue
<ActionSheet
  v-model:visible="visible"
  title="选择"
  :actions="actions"
  @select="onSelect"
/>
```

### Q2: 如何迁移 uni.showToast？
```typescript
// Before
uni.showToast({ title: '成功', icon: 'success' })

// After
import { useToast } from '@/composables/useComponents'
const toast = useToast()
toast.success('成功')
```

### Q3: 新组件如何主题适配？
所有组件都使用 SCSS 变量，自动适配主题色：
```scss
$color-primary: #71585C;
$color-accent: #FF6B8A;
```
