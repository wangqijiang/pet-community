# 宠物社区应用 - 交互组件系统设计

## 📋 组件体系概览

### 一、反馈类组件
用于向用户提供即时反馈和状态提示

#### 1. Toast（轻提示）⭐⭐⭐⭐⭐
**用途**：显示简短的消息、状态反馈、操作结果
**类型**：
- `success`：操作成功
- `error`：操作失败
- `warning`：警告提示
- `info`：普通信息
- `loading`：加载中

**特性**：
- 自动消失（可设置时长）
- 支持图标
- 支持自定义内容
- 居中显示
- 遮罩层可选

#### 2. Loading（加载状态）⭐⭐⭐⭐⭐
**用途**：显示加载状态，阻止用户操作
**类型**：
- 页面级加载
- 局部加载
- 全屏加载

**特性**：
- 可配置遮罩
- 可配置文案
- 支持自定义图标

#### 3. Dialog（对话框）⭐⭐⭐⭐⭐
**用途**：需要用户明确确认或取消的操作
**类型**：
- `alert`：警告弹框（只有一个确认按钮）
- `confirm`：确认弹框（确认+取消按钮）
- `success`：成功提示
- `error`：错误提示
- `custom`：自定义内容

**特性**：
- 遮罩层
- 标题、内容、按钮可配置
- 按钮颜色可定制
- 点击遮罩可关闭（可选）

### 二、选择类组件
用于从多个选项中进行选择

#### 4. Picker（选择器）⭐⭐⭐⭐⭐
**用途**：单列或多列数据选择
**类型**：
- 单列选择器
- 多列选择器（联动/不联动）

**特性**：
- 底部弹出
- 滚动选择
- 确认/取消按钮
- 默认值设置
- 数据联动支持

**应用场景**：
- 宠物种类选择
- 性别选择
- 城市选择

#### 5. DatePicker（日期选择器）⭐⭐⭐⭐
**用途**：选择日期
**类型**：
- 日期选择（年-月-日）
- 时间选择（时:分）
- 日期时间选择

**特性**：
- 范围限制
- 格式化显示
- 默认值
- 快捷操作

**应用场景**：
- 宠物生日选择
- 预约时间选择

#### 6. CascadePicker（级联选择器）⭐⭐⭐
**用途**：省市区三级联动选择
**特性**：
- 自动联动
- 数据格式支持
- 自定义数据结构

**应用场景**：
- 地址选择

### 三、操作类组件
用于特定的操作场景

#### 7. ActionSheet（操作菜单）⭐⭐⭐⭐⭐
**用途**：展示多个操作选项
**特性**：

- 遮罩层
- 取消按钮

**应用场景**：
- 动态更多操作（编辑、删除、分享）
- 图片操作（拍照、从相册选择）

#### 8. Popup（弹出层）⭐⭐⭐⭐
**用途**：自定义内容弹出
**类型**：
- 居中弹出
- 顶部弹出
- 底部弹出

**特性**：
- 遮罩层
- 关闭按钮
- 拖拽关闭
- 圆角定制

#### 9. BottomSheet（底部弹出）⭐⭐⭐⭐
**用途**：从底部弹出的面板
**特性**：
- 可拖拽
- 高度可配置

**应用场景**：
- 评论列表

**应用场景**：

#### 13. Checkbox（复选框）⭐⭐⭐⭐

## 🔧 使用方式

### 全局注册
在 `main.ts` 或 `App.vue` 中全局注册组件：
```typescript
import { createApp } from 'vue'
import App from './App.vue'

// 导入所有组件
import components from './components'

const app = createApp(App)

// 全局注册
app.use(components)

app.mount('#app')
```

### 组件调用
```vue
<template>
  <!-- Toast -->
  <button @click="showToast">显示提示</button>

  <!-- Picker -->
  <button @click="showPicker">选择宠物种类</button>

  <!-- Dialog -->
  <button @click="showDialog">显示对话框</button>
</template>

<script setup>
import { useDialog, useToast, usePicker } from '@/composables/useComponents'

const toast = useToast()
const dialog = useDialog()
const picker = usePicker()

const showToast = () => {
  toast.success('操作成功')
}

const showDialog = () => {
  dialog.confirm({
    title: '确认删除',
    content: '确定要删除这条动态吗？',
    confirmText: '删除',
    confirmColor: '#FF6B8A',
    success: () => {
      // 删除操作
    }
  })
}

const showPicker = () => {
  picker.show({
    title: '选择宠物种类',
    data: ['猫咪', '狗狗', '兔子', '仓鼠'],
    success: (value) => {
      console.log('选择了:', value)
    }
  })
}
</script>
```
