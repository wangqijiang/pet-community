# WaggleWorld 小程序完整开发计划

## 项目概述
基于 WaggleWorld.md PRD 文档，完整实现宠物社交小程序的所有功能模块和页面。

## 技术栈
- **框架**: uni-app
- **前端**: Vue 3.2 Composition API
- **样式**: SCSS (rpx单位)
- **平台**: 微信小程序

## 项目规模
- **4大核心模块**
- **19个页面**（4个主页面 + 15个子页面）
- **5个全局组件**

## 七、技术要点

### 1. 地图功能
- 使用 uni-app 的 `<map>` 组件
- 自定义标记点样式
- 标记点点击事件
- 地图中心点定位

### 2. 图片上传
- 使用 `uni.chooseImage` 选择图片
- 图片压缩
- 图片预览
- 多图上传

### 3. 下拉刷新和上拉加载
- 使用 `onPullDownRefresh` 和 `onReachBottom`
- 分页加载数据
- 加载状态管理

### 4. 数据持久化
- 使用 `uni.setStorage` 和 `uni.getStorage`
- 用户信息缓存
- Token 管理

### 5. 交互动效
- 所有按钮按下缩放至 0.98
- 震动反馈（light/medium）
- 页面切换动画
- 弹窗动画

## 八、开发规范

### 1. 文件命名
- 页面文件：kebab-case（如 `friend-list.vue`）
- 组件文件：PascalCase（如 `TopNavBar.vue`）
- 样式文件：kebab-case（如 `variables.scss`）

### 2. 代码规范
- 使用 Vue 3.2 Composition API
- 使用 `<script setup>` 语法
- 使用 SCSS 预处理器
- 单位统一使用 rpx

### 3. 样式规范
- 所有颜色使用变量
- 所有间距使用变量
- 圆角统一 24rpx
- 按下缩放统一 0.98

### 4. 注释规范
- 每个页面顶部添加功能说明
- 复杂逻辑添加注释
- 组件 props 添加类型和说明
